# 氏名突合支援 API (Excel サンプルコード)

## 概要

ExcelのVBAを用いてExcel関数を作成し，関数をスプレッドシートに埋め込むことで氏名突合支援 API にアクセスし，結果を取得するプログラムです。

## API キーの取得

事前に https://kktg.digital.go.jp/ から、API キーを取得してください

## 使い方

### 氏名漢字カナ突合機能
```
KanjiKana(漢字姓名,カナ姓名,[詳細モデルかどうか])
```

- セルA2に漢字姓名，セルB2にカナ姓名，詳細モデルで実行する
  ```
  =KanjiKana(A2, B2, TRUE)
  ```

- セルA2に漢字姓名，セルB2にカナ姓名，簡易モデルで実行する
  ```
  =KanjiKana(A2, B2)
  ```


## 制限事項
Windows10, 11のOffice365のExcelで実行可能
